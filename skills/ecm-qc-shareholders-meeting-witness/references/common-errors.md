# 常见错误库（Common Error Catalog）

基于 A 股见证业务公开实务经验汇总的高频错误模式，审查时逐条筛查。
各类批注话术统一见 `comment-templates.md`；C/D/E 类的判定规则、法规依据、
矩阵校验见 `voting-rules.md`（唯一定义处）。

## A 类 — 基础信息类（事实错，最高频扣分项）

本质是笔误/复制粘贴残留，但影响严重（决议日期错可能导致决议效力瑕疵）。
发现即 tracked change 改正 + 【必改】批注。

| 编号 | 典型错误 | 检查方法 |
|---|---|---|
| A1 | 股东（大）会**召开日期**错 | 三方对比：意见书 vs 通知 vs 决议公告 |
| A2 | **召开时间**错（AM/PM 混淆、时点错） | 核对通知 |
| A3 | **年份**错（当年会议误写上年年份） | 全文搜索年份 |
| A4 | **届次**错（第几次临时股东会） | 全文搜索届次编号 |
| A5 | **董事会届次/日期**错 | 核对董事会决议公告 |
| A6 | **会议地点**错 | 对照通知地址（逐字） |
| A7 | **公告披露日期**错 | 核对实际公告时间 |
| A8 | **公司简称**前后不一致 | 全文搜索简称 |
| A9 | **议案编号**错 | 逐项对照通知 |
| **A10** | **引用的公告/通知名称与实际披露标题不一致**（尤其"延期/更正/补充"类，如见证写《关于延期召开……的通知》而实际披露标题为《关于召开……的通知（延期后）》） | 见证意见所引书名号文件名 逐字 vs cninfo 实际 `title`（见 `cross-check-matrix.md` 原则 1）|

## B 类 — 议案结构类

| 编号 | 典型错误 | 检查方法 |
|---|---|---|
| B1 | 总议案 vs 子议案混淆（将"统一表决"当成单独议案） | 核对通知议案结构 |
| B2 | 有子议案的议案漏列（处理按 `voting-rules.md` §七，默认只列子议案不批） | 核对提案编码表 |
| B3 | 现场对议案内容临时变更，未按董事会决议披露内容表决 | 核对议案内容与披露内容 |
| B4 | 议案审议/决议章节与通知清单不对应 | 议案完整性矩阵 |

## C 类 — 特别决议类（高频扣分）

| 编号 | 典型错误 | 检查方法 |
|---|---|---|
| C1 | 应为特别决议事项，未标注 | 矩阵 X 第 3 列 |
| C2 | 应写明三分之二以上同意通过，未写 | 全文搜"三分之二""2/3" |
| C3 | 误把非特别决议议案标注为特别决议 | 关键词逆向匹配 |
| C4 | 三会议事规则（章程附件）未列为特别决议（深交所常见；2026 年后"审计委员会议事规则"替代"监事会议事规则"） | 议案标题命中"议事规则修订" |
| C5 | 特别决议议案缺"本项议案为股东会特别决议事项"标准句式 | 表决段核对 |
| C6 | 同意比例 < 2/3，结论却写"通过" | 比例核算 vs 66.67% |
| C7 | "董事会议事规则""审计委员会议事规则"修订未按特别决议处理 | 与 C4 配套，扩大到三会全部 |
| C8 | 性质应为特别决议（发行公司债券、股权激励等），通知和见证均未标注 | 关键词识别 + 与公司核实 |
| C9 | 子议案结构中某些项目应为特别决议但未单独标注 | 子议案逐项识别 |
| C10 | 资本公积转增股本被误标为"增加注册资本"特别决议 | 议案内容辨析 |

## D 类 — 累积投票制类

| 编号 | 典型错误 | 检查方法 |
|---|---|---|
| D1 | 累积投票议案写了"反对""弃权" | 累积投票议案段搜"反对""弃权" |
| D2 | 非累积投票议案漏写"反对""弃权" | 选举议案是否等额 |
| D3 | 未列当选人（"根据表决结果，XXX 当选为 XXX"） | 表决段末搜"当选" |
| D4 | 误写"同意/反对/弃权"三栏统计 | 表格结构核对 |
| D5 | 未说明"采用累积投票制" | 表决段开头 |
| D6 | 独董与非独董合并计票（应分议案分别累积投票） | 议案是否拆分 |
| D7 | 等额选举却启用累积投票 | 候选人 vs 应选名额 |
| **D8** | **应选 ≥ 2 名且（选举 ≥ 2 名独董 / 单一股东及一致行动人持股 ≥ 30% 选举董事）时未采用累积投票**（强制） | 候选人数 + 控股股东持股 |
| **D11** | **只选举 1 名董事/监事却被批"应核实/采用累积投票"**（误判）——单候选人选举累积投票无意义，不适用、不披露，即使有 30% 控股股东也不触发 | **先数应选名额，=1 直接跳过累积投票全部校验**（`voting-rules.md` §三"适用前提"）|
| D9 | 职工代表董事被纳入股东会议案（应由职代会选举） | 议案主体核对 |
| D10 | 罢免议案被误按累积投票处理 | 罢免应为普通决议 |

## E 类 — 关联回避与中小投资者单独计票类

| 编号 | 典型错误 | 检查方法 |
|---|---|---|
| E1 | 通知未列具体关联股东回避名单 | 通知"回避名单"段 |
| E2 | 通知未列明的关联股东未核查即列在意见书中 | 名单一致性 |
| E3 | 通知明确单独计票议案，意见书未列计票结果 | 表决段搜"中小投资者……股" |
| E4 | 隐性关联识别不彻底（亲属、曾任职、受益人等） | 关联股东穿透核查 |
| E5 | 关联股东名单与通知不一致 | 三方对照 |
| E6 | 通知"全部议案均单独计票"，意见书仅对部分议案列示 | 矩阵 Z 逐项检查 |
| E7 | 性质应单独计票但通知漏标、意见书亦未列示 | `voting-rules.md` §四反向识别 |
| **E8** | "中小投资者"定义中仍含"监事"——**以【核实】提示项目组核实公司是否已撤销监事会，不径行【必改】** | 全文搜"中小投资者，是指" |
| E9 | 关联回避 + 单独计票同时适用时口径混算 | 表决基数核对 |
| E10 | 单独计票比例分母错（应为"出席会议中小投资者及中小投资者代理人有表决权股份总数"） | 比例公式核对 |
| E11 | 总表决结果与单独计票结果之和数字矛盾 | 数字交叉核算 |
| **E12** | 任何位置残留"监事""监事会"字样——**【核实】提示核实，软处理**（见 `voting-rules.md` §四监事会撤销规则） | 全文搜"监事" |
| E13 | 从通知提取关联回避名单时**漏掉"等"字**，把"……等关联股东"开放式表述写成封闭具名清单 | 核对通知回避名单是否含"等"（见 `cross-check-matrix.md` 原则 1）|

## F 类 — 模板残留类（复制粘贴没删干净）

| 编号 | 典型错误 | 检查方法 |
|---|---|---|
| F1 | 不涉及网络投票却保留"网络投票的统计结果……" | 全文搜"网络投票" |
| F2 | 挂牌公司未删除《股东会规则》引用 | 全文搜"股东会规则" |
| F3 | 《股东大会规则》未更新为《股东会规则》（2025 年修订更名） | 全文搜"股东大会规则" |
| F4 | 深交所公司引用上交所投票系统地址（反之亦然） | 全文搜"投票系统" |
| F5 | 任职人员已离职仍保留其出席表述（如董秘离职未更新） | 与公司核实 |
| F6 | 结论意见段缺失（漏了第三章表决部分结论段） | 章节末尾核对 |
| **F7** | **"具体时间以董事会发出的会议通知为准"冗余**——同次董事会已定股东会日期则属模板残留；公司确实开两次董事会（先决定开会、再定日期发通知）的保留无误 | 对照董事会决议公告：同次已定日期 → 必改；多次会议 → 保留 |
| **F8** | **"中国台湾地区""台湾"等非规范用语**（应为"中国台湾省"） | 全文搜"台湾" |
| **F9** | **页眉/Logo/抬头含 "Mallesons"** | 跑 `extract_images.py` 读图，见 `checklists.md` §二 |
| **F10** | **法律适用范围未排除港澳台**（错写"包括…中国台湾省"，应为"不包括"） | 搜"中华人民共和国" + "包括" |

## 审查顺序建议（效率最高）

1. **A 类快扫全文**——日期/届次/地点/年份/简称错误一遍消灭大半
2. **F 类模板残留扫**——《股东会规则》更名、网络投票残留、挂牌公司法规、
   F7-F10 新增高频项
3. **三种特殊表决方式专项**（最优先级）——按 `voting-rules.md` 三步法打标签、
   摘通知标注、填矩阵 X/Y/Z、写批注
4. **C/D/E 逐项过**（重点新增高危项 C6-C10 / D5-D10 / E6-E12）
5. **G 类**章程引用
6. **B 类**议案结构 + **H/I 类**底稿与程序
